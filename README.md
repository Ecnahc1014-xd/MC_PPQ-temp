# MC_PPQ（临时分享）

用于临时分享的 Blender 工程文件，拿到链接即可下载，无需登录。

## 下载方式

- 打包下载全部文件（zip）：<https://github.com/Ecnahc1014-xd/MC_PPQ-temp/archive/refs/heads/main.zip>
- 或在页面上点 **Code → Download ZIP**
- 也可以直接克隆：

```bash
git clone https://github.com/Ecnahc1014-xd/MC_PPQ-temp.git
```
